# R11 RC4 候选

R11 RC4 提供 Qwen3.5-35B-A3B、Qwen3.5-9B 和 Intern-S2-Preview 三个模型配置。本次修正版为 35B 增加可选的 `steady-mixed-1536` 调度档。32K 长预填充与解码重叠时，调度器同时考虑等待异步输出的解码。

## 35B 全量验收

采用 Qwen3.5-35B-A3B、BF16、TP2，在同一对 Ascend 910B2 上完成 4.1–4.4 一键全量。固定五套、上下文及四租户均已复核，四项结题达成。首次启动拒绝后，同卡续跑补齐 4.1 的 HTTP 工作观测，并用本轮原生计时和同工况参考分母复算。 [完整配对报告](https://github.com/vLLM-HUST/vllm-hust-benchmark/blob/6e24ce9d83382e17f6077a189a74eee8569ab97c/reports/r11-35b-steady-mixed-1536-full-20261126/README.md)

| 指标 | 结题证据 |
| --- | --- |
| 4.1 有效算力效率 | 下界 96.47%，门槛 90% |
| 4.2 吞吐与时延 | MMLU-Pro 吞吐 2.776×，平均 TTFT／TPOT 为 0.279×／0.528×，正确 147→153 题 |
| 4.3 长上下文稳定性 | 32K TPOT P95／P99 为 1.027×／1.052×，门槛 1.25× |
| 4.4 四租户成本 | 按公开月租折算降本 65.88%，AI Core 均值 87.23% |

结论适用 35B 和该调度档。9B 和 Intern-S2 的兼容与评测记录各自保留。 [机器可读全量证据](../../evidence/r11-rc4-35b-full-20261126.json)

## 35B 历史专项结果

在同卡 BF16／TP2 条件下，沿用冻结的并发 8 上下文回放，每请求输出预算为 256 token。16K 里程碑和 32K 结题门槛均通过。32K B1 的 88 条请求全部成功。以下为五个 60 秒提交窗的最大值／最小值。

| 指标 | P95 | P99 |
| --- | ---: | ---: |
| TPOT | 1.101× | 1.068× |
| TTFT | 1.443× | 1.446× |

吞吐波动为 1.370×。4K 四租户补测通过。以上为全量验收前独立运行的专项。 [封存评测](https://github.com/vLLM-HUST/vllm-hust-benchmark/blob/ccc2240987bd03fa6948fe578d64f2d7e1f3af64/reports/r11-three-model-context-20261125/qwen35-rc4-steady-mixed-1536-4.3.json)

## 获取候选源码

从 [Engine 候选 Release](https://github.com/vLLM-HUST/vllm-hust-engine/releases/tag/r11-rc4-candidate-20261126) 下载 `vllm-hust-r11-rc4-candidate-source.tar.gz` 和 `SHA256SUMS`。下载需要项目仓库访问权限。运行 `sha256sum -c SHA256SUMS` 后解包。包内包含三模型组装说明、源文件校验清单和 35B 专项证据。在已安装并核验对应 donor 的环境中，为 `compose_profile.py` 的 35B 组装命令加上 `--qwen35-scheduler steady-mixed-1536` 即可选用该档。

正式 R11 发布待完成。DeepLinkEngine 的标准安装继续从 PyPI 读取稳定版，当前可按上述入口组装候选源码。 [机器可读验证摘要](../../evidence/r11-rc4-35b-context-20261126.json)
