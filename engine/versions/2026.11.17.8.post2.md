# 2026.11.17.8.post2 版本说明

[下载冻结 r8 发行包](https://github.com/DeepLinkNext/DeepLinkEngine/releases/download/r8-runtime-dependencies-20261119-v1/vllm_hust_engine-2026.11.17.8.post2.tar.gz)。包与 [PyPI 2026.11.17.8.post2](https://pypi.org/project/vllm-hust-engine/2026.11.17.8.post2/) 的发行包一致。冻结引擎提交为 `c6059a6d3d1cf7ea16340d79cccf7bb1a13fa661`，随附评测工具提交为 `bd5448c9f266cc0301c3d4cef2a10b9ab98f7205`。发行包中的 `sdk-r8.tar.gz` 包含冻结 SDK、vLLM 和 vLLM-Ascend 源码、MOD 与部署配置，`tools-r4.tar.gz` 是该 r8 版本一并锁定的评测工具归档。

## 下载与校验

固定依赖、引擎包、评测工具和参考材料统一存放在[依赖下载中心](https://github.com/DeepLinkNext/DeepLinkEngine/releases/tag/r8-runtime-dependencies-20261119-v1)；[完整索引](../dependencies.json)记录版本、文件大小、SHA-256 和原来源。后续查找与下载均从此入口开始。

在仓库根目录运行，路径填入实际下载位置：

```sh
python tools/verify_snapshot.py --engine /path/to/vllm_hust_engine-2026.11.17.8.post2.tar.gz
```

脚本核验发行包 SHA-256、内部 SDK 和工具包身份，并将包内评测协议与仓库清单逐一对照。[依赖下载中心](https://github.com/DeepLinkNext/DeepLinkEngine/releases/tag/r8-runtime-dependencies-20261119-v1) 同时提供三个配套轮包及独立的评测工具包。发行包和轮包的来源、文件大小和 SHA-256 见 [r8-lock.json](../r8-lock.json)。

```sh
python tools/verify_snapshot.py --tools /path/to/tools-r4.tar.gz
tar -xzf /path/to/tools-r4.tar.gz
python vllm-hust-engine/one_click.py prepare --help
```

解包后即可查看该冻结版本的 `one_click.py`、`scripts/`、`protocols/` 和 `examples/`。该归档保留历史身份；新的第三方测试请使用仓库根目录的 `python one_click.py run --config evaluation.json`，其[修正版工具及参考证据锁](../../benchmark/one-click-lock.json)独立版本化，自动生成本轮参考认证。

## 安装

| 项目 | 固定环境 |
| --- | --- |
| 设备及模型 | 双昇腾 910B2，Qwen3.5-35B-A3B，BF16，TP2 |
| 运行平台 | Linux aarch64，CPython 3.12，CANN 9.1.0 |
| Python 依赖 | Torch 2.13.0+cpu、TorchVision 0.28.0+cpu、Torch-NPU 2.13.0rc1、Triton-Ascend 3.6.0、Transformers 5.14.1、tokenizers 0.22.2 |

在仓库根目录执行独立安装，再启动推理服务：

```sh
python deeplink.py install --out /workspace/deeplink-install
python deeplink.py serve --installation /workspace/deeplink-install \
  --model /models/Qwen3.5-35B-A3B --physical-devices 0,7
python examples/chat.py "你好"
```

安装自动准备专用 venv，按锁定索引下载、验哈希后从本地安装四个引擎包，并校验 9,235 个运行时文件。依赖解析结束后，还会核对 Ascend Triton 的 565 个已登记文件；发现通用 Triton 覆盖厂商文件时，从锁定轮包恢复并重新校验。环境准备日志实时跟随终端，原始日志留在缓存中，校验收据随结果保存。服务启动采用该版本的 FULL 图、MTP2、TP2、36 执行席位和 54 常驻席位配置；当前面向文本聊天。无需评测数据、B0 或参考认证。系统 CANN、ATB 和驱动需预先安装，当前运行时要求 `/usr/local/Ascend/cann-9.1.0` 及 `/usr/local/Ascend/nnal/atb`。完整选项见[安装与服务说明](../README.md)。

原包名和内部 CLI 保持发行身份；手工准备环境后仍可使用 `vllm-hust-engine verify`、`vllm-hust-engine install`。新的配对测试使用[仓库根入口](../../benchmark/README.md#昇腾实机配对测试)。

## 版本与命名

仓库和发行入口使用 **DeepLinkEngine**。冻结发行包沿用 `vllm-hust-engine` 包名和 CLI，安装包及轮包的文件名、版本与 SHA-256 保持原有身份。锁文件中的 `deepengine_url` 字段，以及公开 JSON 中的 `deepengine-*` schema 标识，保留为已有数据格式的兼容字段；下载地址已指向本仓库的新名称。

四个引擎包也可提前下载：`python engine_install.py --download-only --cache /path/to/cache`。`--wheelhouse /path/to/wheels` 可复用离线包，包身份与上游冻结清单一致。

## 自动环境准备

默认无需增加配置。依赖下载到配置中的缓存目录，修复记录随结果保存在 `environment.json`。仅准备环境可执行 `python run_all.py --config evaluation.json --prepare-environment`。已有离线包或非默认安装路径时，可选填写 `environment` 对象中的 `wheelhouse`、`python`、`cann_home`，相对路径以配置文件为准。

Triton-Ascend 3.6.0 使用[已核验的恢复包](https://github.com/DeepLinkNext/DeepLinkEngine/releases/tag/r8-runtime-dependencies-20261119-v1)，下载时核对固定 SHA-256。包内代码和二进制保持原安装记录的字节；原始 wheel 缺失，恢复来源及新旧归档身份随 Release 公布。
