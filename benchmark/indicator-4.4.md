# 指标 4.4 单位输出 token 成本及利用率

## 公开报价与历史估算算法

参照上海有色网于 2026 年 11 月 17 日报道的昇腾 910B2 八卡服务器整机月租报价，按 15,000 元除以 8 张卡，取 **1,875 元/卡月**。B0 和 B1 使用同一对昇腾 910B2 卡，以相同费率和 30 天折算月分摊整机月租。下列金额均为报价折算的测算值。[公开报价](https://news.smm.cn/news/TCNOQJBAJVZYJ73BMVU7G5GJZXQ462A4U6NN4CY)

设 `P` 为每卡月费、`k` 为占用卡数、`T` 为正式提交开始至排空的秒数、`N` 为同窗成功输出 token 数。区间估算费用 `A = P × k × T ÷ (30 × 86400)`，每百万输出 token 估算成本 `c = 10⁶ × A ÷ N`，降幅为 `(1 − c₁/c₀) × 100%`。共同费率和折算天数可在降幅公式中约去。

## 第三方现场测试

冻结 V2 的里程碑使用 MMLU-Pro 200 题完整回答（并发 200、最多输出 8192、正常 EOS），结题使用 4K 四租户 C24。统一入口保存两臂正式提交至排空的时间、卡数、成功输出词元、同窗双卡 AI Core 采样和逐租户回执。实际单位成本以两臂各自的实际每卡综合月费计算，包括卡及对应主机、内存、电力和运维，同一费用项计入一次。实际费用由账单、合同或分摊底稿核对，按人民币元/卡月归一化。

### 随封存回执提交实际费用

完整入口在报告内为未提交费用的工况生成 `actual-cost.template.json`，已填入 B0、B1 各自的测量封存 SHA-256。填写经核对的每卡综合月费和凭据文件及其 SHA-256。已有部分费用时，把模板中的待补工况加入原清单。支持 `mmlu` 与 `four_tenant`，每项均需两侧凭据。下面展示单个工况的结构。

```json
{
  "schema": "deeplinkengine-v2-actual-card-cost/v1",
  "scenarios": {
    "mmlu": {
      "B0": {
        "measurement_seal_sha256": "<B0 测量封存 SHA-256>",
        "monthly_cost_per_card_cny": "<B0 实际每卡综合月费>",
        "evidence": [{"file": "b0-cost.pdf", "sha256": "<费用凭据 SHA-256>"}]
      },
      "B1": {
        "measurement_seal_sha256": "<B1 测量封存 SHA-256>",
        "monthly_cost_per_card_cny": "<B1 实际每卡综合月费>",
        "evidence": [{"file": "b1-cost.pdf", "sha256": "<费用凭据 SHA-256>"}]
      }
    }
  }
}
```

文件路径可相对于清单目录。费率核对、费用分摊和凭据真实性由提交方及见证方确认，脚本校验凭据文件、测量封存和数值并复算。报告保留费用清单及凭据摘要，费用原件按交付权限单独归档。

将费用清单保存为原运行输出目录下的 `actual-cost.json`，或在原配置中设置 `"actual_cost": "private/v2-cost.json"`。配置路径相对于配置文件。两种接入方式均由完整入口自动读取；已封存轮次用原配置复算。

```sh
python run_all.py --config evaluation.json --report-only
```

临时指定的 `--actual-cost` 优先于配置和默认路径。独立 CPU 复算配置只需 `out` 与 `cache`，以及需要时的 `actual_cost`。复算写入新报告目录，保留原测量与原报告。缺凭据的工况显示待实际费用凭据，同费率估算单列。

## 历史预检配对结果

单位成本展示至小数点后三位，降幅按未舍入的原值计算。

| --- | --- | ---: | ---: | ---: | ---: | ---: | ---: |
| MMLU-Pro 200 题完整回答 | B0 | 2 | 1426.006 | 721,900 | 2.0631 | 2.858 | 33.23% |
| MMLU-Pro 200 题完整回答 | B1 | 2 | 477.533 | 690,468 | 0.6909 | 1.001 | 78.56% |
| 四租户 C24 | B0 | 2 | 311.537 | 40,192 | 0.4507 | 11.214 | 30.66% |
| 四租户 C24 | B1 | 2 | 308.368 | 110,592 | 0.4461 | 4.034 | 85.72% |

MMLU-Pro 的估算单位成本下降 **64.99%**，同窗双卡 AI Core 利用率提高 **45.33 个百分点**。四租户的估算单位成本下降 **64.03%**。以下链接用于复算历史预检数据。[估算数据与来源](../evidence/indicator-4.4-cost-estimate.json) · [MMLU-Pro 同窗记录](../evidence/mmlu-r8-window.json) · [四租户配对记录](reports/r8-context-tenant-20261119/summary-public-v1.json)
